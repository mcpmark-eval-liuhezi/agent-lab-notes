# Contributing to agent-lab-notes

Thanks for your interest in contributing to agent-lab-notes! This document explains how to get involved.

## Ways to help

- **Write up experiments** — add notes, observations, and results from agent experiments.
- **Improve documentation** — clarify existing write-ups, fix typos, and restructure where things are hard to follow.
- **Review pull requests** — read proposed changes and leave constructive feedback.
- **Report problems** — open issues for anything that's confusing, missing, or broken.

## Ground rules

- Be kind and constructive. Assume good intent, and critique ideas rather than people.
- Keep contributions focused — one topic or change per pull request.
- Write clearly and concisely; prefer short paragraphs and plain language.
- Reference the relevant issue in your pull request description.
- Before opening a PR, check for existing work to avoid duplicates.
